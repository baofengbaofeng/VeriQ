# VeriQ 前端验收指南

## 真实入口和夹具

- 从相应 Web 路由进入实际页面。资源列表、菜单、抽屉和写入可从 `/resources/datasets` 或改动的资源
  路由核对。工作区成员、邀请和权限从 `/workspaces` 的实际页签核对。管理表格和独立登录分别从
  `/admin/users` 和 `/login` 核对。用真实页面、已登录且授权适当的角色和隔离的 MySQL 夹具。
  [Web 路由][路由] · [Playwright 业务配置][业务配置] · [开发指南][开发]
- 无法或无需启动完整业务时，独立组件夹具可验证生产组件的渲染、拖动、字段帮助、嵌套关闭和焦点。
  组件夹具仅证明实际测到的组件交互。持久化、权限、业务回执和真实路由使用完整业务套件核验。
  [组件测试配置][组件配置] · [组件交互用例][组件交互]
- 共享视图影响桌面，或改动 Electron 渲染层时，从桌面真实窗口走受影响的交互。`@veriq/web/desktop`
  暴露共享视图，Electron 渲染入口使用 `AppLocaleProvider`，后者挂载共享结果弹窗。核对实际窗口的
  默认和最小尺寸、宿主焦点、关闭及共享反馈。涉及生产工作流时按桌面指南准备匹配引擎和浏览器等夹具。
  [Web 共享入口][共享] · [Electron 渲染入口][渲染] · [窗口尺寸][窗口] · [桌面指南][桌面]

## 浏览器证据

- Web 在 1280 × 800 CSS 像素下验证简体中文和英文。在相关用例设置
  `await page.setViewportSize({ width: 1280, height: 800 })`。用长文案和长数据读取实际计算字号、
  按钮点击尺寸和页面及表格容器的滚动范围。核对菜单 14px、正文和表格 12px、文字最大 16px。
  现有紧凑字号回归可帮助定位断点，验收本次区域时以当前字号规范为准。
  [布局用例][布局] · [界面规范][规范]
- 表单中核对必填标记及语义包含已有默认值的必填控件，例如邀请弹窗中预选角色的下拉框。红色星号
  位于标签文案左侧，可选字段和可选筛选控件省略星号。短提示和长帮助入口均位于相应控件下方。
  验证控件的可访问名称为标签文案，短提示可作为描述读取，长帮助可通过键盘打开。核对短提示和
  展开后的输入说明文案的实际计算字号均为 10px。[字段规范][字段]
- 在 Workspace settings 的 Members 列表等受影响的工具栏中，核对搜索和筛选均省略 `?` 帮助入口，
  并验证搜索框的可访问名称、占位提示及筛选标签与控件的对齐。读取下拉控件的选值、展开后的选项及
  相邻标签或正文的实际计算字号，确认一致。[字段规范][字段]
- 逐一盘点页面、详情、弹窗、抽屉和消息内的表格，包括桌面共享入口。在现有字号和深浅主题下，验证
  Basic Table 5 工具栏左侧只有每页数量，右侧依次放常显搜索、筛选、查看全部和下载。核对邀请加号
  位于 Invitations 区块标题右侧、下载图标和文字垂直居中。用键盘操作筛选面板并核对关闭后的焦点。
  带搜索和筛选换页后，点查看全部，核对回到第一页、搜索与筛选已清空、每页数量和授权范围仍然有效。
- 核对 Data Table 3 表身和页脚的原字号、页脚左侧的记录范围及右侧的页码。改变每页数量、搜索或翻页
  时比对可见行和计数，游标表核对末页和总数未定时的真实范围。检查列标题语义、键盘访问截断值及表身
  内部横向滚动。[数据表格规范][数据表格] · [表格与资源菜单][资源菜单] · [工作区表格][工作区表格]
- 实际点下载并读取 CSV 文本，核对它与当前页可见授权列、行顺序一致，逗号、引号及换行不破坏列结构，
  公式文本保持为普通值。验证空结果、加载或失去权限时的下载状态。[组件交互用例][组件交互]
- 分别验证没有记录和筛选无匹配。两种情况下核对表头仍可见且保留列标题语义，`tbody` 的空态单元格
  跨越当前所有可见列，提示文字在单元格内居中且符合当前状态。[表格空态][空态]
- 在默认字号、可用字号档位及浏览器缩放下，比较上一页、页码、下一页与正文的实际计算字号。核对当前
  页按钮框随文字行高和纵向内边距自然撑开，文字完整显示，并用 Tab 和 Enter 验证可见焦点和换页。
  [数据表格规范][数据表格]
- 核对提交为蓝色、删除入口与确认删除为红色。验证修改动作的成功、拒绝或失败、取消及适用快捷键。
  延迟业务响应，确认同一个共享 Dialog 从进行中切换为最终结果，受理或排队仍显示进度，结果只出现
  一次。比较弹窗前后背景表单、工具栏和列表的位置及尺寸，核对失败保留输入，列表加载独立播报状态。
  [结果用例][操作结果] · [资源写入用例][资源结果]
- 用角色、可访问名称和标签定位控件。用 Tab、方向键、Enter、Space 和 Escape 检查相关帮助、选值、
  菜单导航和最上层弹层关闭，核对焦点回到原入口或合理后备位置。抽屉还需验证直角、一开始占视口
  三分之一、左缘拖动、全宽往返及草稿保留。[抽屉宽度用例][抽屉] · [组件交互用例][组件交互]
- 在浅色、深色和系统强制配色下，通过键盘和指针核对常规控件选中、聚焦以及已选中时再聚焦的背景变化。
  核对普通输入框和文本域在聚焦前后的 TailAdmin 默认底色一致，自身边框颜色显示焦点。确认控件内容
  可读，省略额外的灰色外框或阴影描边，常态边界和校验反馈仍可辨识。[焦点规范][字段]
- 用键盘操作横向 Tabs，核对当前页签的底部品牌色下划线与焦点背景可分别辨认。同时选中和聚焦时，
  两种提示同时可见。焦点离开时恢复常态背景并保留下划线。核对无额外灰色外框。
  [工作区页签与角色][工作区权限] · [焦点规范][字段]
- 在默认和紧凑视口下测量触发控件与下拉菜单的宽度。用短文案核对菜单贴合触发控件和选项所需宽度，
  用长文案核对菜单随内容拓宽并限制在视口可用宽度内。核对单行选项与收起的触发控件等高、文字垂直
  居中，菜单上下边缘及选项间距紧凑。达到宽度上限时，换行选项自然增高且文字完整。[下拉规范][字段]
- 分别用鼠标悬停和方向键聚焦下拉选项，核对悬停有轻微底色变化，键盘焦点有独立背景色。已选中
  选项在悬停或聚焦时仍可辨认，三种状态可区分。[下拉规范][字段]
- 涉及权限时，以适当的已授权角色和受限角色验证可见菜单、可操作项和真实业务响应。工作区切换、
  归档或失去访问权后，核对旧数据和旧操作不会出现在当前视图。状态徽标还需确认文字和主题下的对比。
  [工作区页签与角色][工作区权限] · [状态徽标][徽标]

## 运行入口与交付

在仓库根目录运行和任务相关的命令。先以现有用例定位，再选择对应的完整套件。以下用资源菜单
举例，组件用例单独配置。[Web 包命令][Web 包] · [测试规范][测试规范]

```sh
pnpm --filter @veriq/web check
pnpm --filter @veriq/web exec playwright test tests/console/resource-menus.spec.ts
pnpm --filter @veriq/web exec playwright test --config playwright.interactions.config.ts
pnpm --filter @veriq/web test:e2e
```

涉及桌面时，按桌面指南准备已锁定的工具链、测试数据库和宿主环境，再运行适用的桌面命令。
[桌面包命令][桌面包] · [桌面指南][桌面]

```sh
pnpm --filter @veriq/desktop check
pnpm --filter @veriq/desktop build
pnpm desktop:test
```

交付时记录实际命令、环境、入口、CSS 视口、语言、角色和观察到的状态。逐项报告通过、失败与阻塞。
缺少匹配浏览器、数据库、引擎或桌面宿主夹具时，说明受影响的验收项。涉及敏感数据时保留脱敏证据。
