# VeriQ 前端界面规范

## 字号、视口和布局

- 界面文字最大 16px，菜单 14px，正文、表头和单元格 12px，字段输入提示 10px。常规操作按钮显式
  设置尺寸，核对实际占用和点击区域。若与现有字号偏好冲突，在方案中说明影响与处理方式。调整字号
  偏好前须取得用户明确同意。
- Web 最低支持视口为 1280 × 800 CSS 像素。保留该尺寸下的字号要求，核对现有紧凑断点对改动区域的
  影响。界面及表格文字保持单行，下拉选项的长文案按组件规则处理。先安排表头和内容列宽，仍需截断
  时，提供可通过键盘访问完整值的入口。宽表格在自身区域横向滚动，页面整体保持宽度稳定且无横向溢出。
- 在现有页面壳层内安排标题、页面操作、筛选区和表格。筛选和换页时保留表头与列对齐。
  通过面包屑及当前导航状态表示层级，明确主操作和行内操作的作用范围。[组件索引][组件]
- 共享视图还须在 Electron 原有独立窗口尺寸下验证，保留宿主窗口尺寸规则。[Electron 窗口]

## 数据表格

- 所有表格统一复用 VeriQ 的 `DataTable`，表身和页脚只采用 Data Table 3。适用于 Web 和 Electron
  共享视图、只读详情、弹窗和抽屉内的编辑或预览表，也适用于消息中实际渲染的数据表格。沿用现有字号、
  主题和控件风格。
  [TailAdmin React 示例][Data Table 3] · [共享表格][DataTable]
- 工具栏采用 Basic Table 5 的分组。左侧只放每页数量，右侧依次放常显的独立搜索框、筛选（Filter）、
  查看全部（See all）、下载（Download）。下载图标与文字在按钮内垂直居中。各项业务筛选集中在
  筛选入口，保留查询语义和权限。无业务筛选的表格省略筛选按钮。已有新增及行内操作沿用各自的职责
  和授权。邀请成员的加号按钮放在 Invitations 区块标题的右侧。
  [TailAdmin React 示例][Basic Table 5]
- 查看全部清空本表的搜索与筛选并回到第一页，保留每页数量和当前可见数据的授权范围。筛选面板与
  工具栏沿用现有字号及深浅主题。筛选入口支持键盘打开和操作，关闭后焦点回到触发按钮。
- Data Table 3 的页脚左侧显示当前记录范围和实际匹配总数，右侧放上一页、页码和下一页。游标接口
  总数未知时显示实际范围，按真实游标决定可用页。每页数量或搜索变化后回到第一页。窄容器内工具栏
  与页脚可换行，表身单独横向滚动。分页字号沿用正文，页码按钮高度由行高和内边距自然撑开，支持
  键盘选值、换页和可见焦点。
- 下载将当前页可见且已授权的业务列写入 CSV，由调用方显式声明导出字段。过滤、分页与读取权限沿用屏幕
  当前展示范围。排除操作列和未展示的内部字段，正确转义分隔符、引号、换行及可能被当成公式的文本。
  工作区表格按当前工作区的下载权限启用导出；授权未确认、没有可下载的行或数据未就绪时禁用下载。
- 表格无记录或筛选无匹配时，保留 `thead`、列标题语义、工具栏和页脚。在 `tbody` 的一行内用一个单元格
  横跨所有可见列，居中显示相应空态。加载和读取失败沿用所在页面的提示。

## 操作、状态和授权

- 提交按钮用蓝色 `primary`，删除入口和确认删除按钮用红色 `danger`。其他按钮按操作用途选择颜色。
- 执行前确认使用 `ConfirmDialog`。用户主动发起且需要等待的操作在单个共享 Dialog 中显示进行中，收到
  最终结果后在原弹窗切换成成功或失败。受理或排队作为进度显示。弹窗期间背景的表单、列表和工具栏
  保持原布局。键盘快捷键走同一反馈路径，每次操作只发布一次结果。列表加载沿用页面内的 `status`。
- 导航、打开抽屉和纯视图切换通过对应界面状态体现。区分加载、无记录、筛选无匹配、失败和无权访问，
  保留可重试或可继续编辑的状态。记录状态用本地化文字表示，并以颜色辅助辨识。
- 菜单、批量操作和确认入口沿用当前工作区、资源与角色的权限判断；用可观察的禁用或只读状态表达
  当前范围。受限入口、数据读取和写操作须遵守相应服务端授权。切换工作区后同步核对当前选择和
  可操作项。[公共契约]

## 字段、键盘和本地化

- 表单字段按标签、控件、提示的顺序排列。按业务或控件的必填规则在标签文案左侧显示红色 `*`，带有
  默认值或预选项的必填字段同样标记。可选字段和可选筛选控件省略星号。必填控件保留必填语义，星号
  从无障碍名称中隐藏。为控件关联可见标签，并通过 `aria-describedby` 关联其下方的可见提示。
  密集布局可在控件下方使用与字段关联的 `?` 帮助入口，支持键盘聚焦并展开完整说明。短提示与展开
  后的输入说明文案均使用 10px。占位符只补充输入示例。字段校验错误使用预留区域或浮层，避免表单
  内容随反馈跳动。[字段入口][Field]
- 列表工具栏的搜索和筛选省略 `?` 帮助入口。搜索框使用简短的占位提示和可访问名称，筛选的可见
  标签与控件同行。下拉控件中的选值和展开后的选项沿用相邻标签或正文的字号。[成员工具栏][成员工具栏]
- 下拉菜单宽度取触发控件宽度和选项所需宽度中的较大者，以视口内的可用宽度为上限。短选项菜单保持
  紧凑，长选项可拓宽菜单，达到宽度上限时换行。单行选项与收起的触发控件等高，文字垂直居中。多行
  选项随内容撑开，菜单上下边缘和相邻选项保持紧凑。共享下拉沿用 TailAdmin 默认底色，通过对勾标明
  已选项。鼠标悬停时使用轻微的背景色变化，方向键移动焦点时使用可辨识的独立背景色。
- Web 和桌面控件通常通过背景色变化呈现焦点和选中，已选中控件的背景仍可提示焦点进入。普通输入框和
  文本域聚焦时保留 TailAdmin 默认底色，通过自身的品牌色边框提示焦点。省略额外的灰色外框或阴影描边。
  浅色、深色主题和系统强制配色均须保留可见的键盘焦点，强制配色使用系统色。保留用于识别控件边界和
  表达校验状态的边框。[Web 样式][Web 样式] · [桌面样式][桌面样式]
- Tabs 采用 Line Variant。横向页签以底部品牌色下划线标记当前项，以背景色变化提示键盘焦点。
  当前页签获得焦点时保留下划线，焦点离开后页签恢复常态背景。省略额外的灰色外框或阴影描边。
- 为图标按钮提供可访问名称，用键盘走通激活、选择、关闭和焦点返回。嵌套弹层的 Escape 先关闭最
  上层。关闭后焦点回到仍在页面的可操作入口。入口已移除时，使用当前页面或列表的适当焦点目标。
- 所有产品文案提供简体中文和英文，包括菜单、帮助、操作反馈、无障碍名称、枚举与状态的显示名称、
  类型与字典标签、下拉选项及错误文案。在 Web 和共享视图复用 `tx`、`useAppLocale` 与现有 i18n
  字典。Electron 渲染层沿用现有双语入口。可按业务含义保留明确的领域术语、标识和用户原始数据。
  产品枚举值应在显示层映射到当前语言。[Web 本地化] · [Electron 文案]

## 右侧抽屉

- 右侧抽屉采用直角，初始宽度为当前视口的三分之一，左缘可拖动。顶部按钮在全宽与三分之一宽度间
  切换，保留编辑内容。`Sheet` 需显式传 `size="third"` 和 `resizable`，顶部按钮回到三分之一时
  会清除拖动宽度。现有调用可能采用其它初始尺寸，核对本次涉及的场景。[抽屉入口][Sheet]
