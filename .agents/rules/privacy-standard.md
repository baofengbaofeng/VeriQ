# Privacy Standard

约束用户数据、证据、日志与备份中的敏感信息处理及保留期，降低泄漏与合规风险。

## 1. 数据分类（实现时按类处理）

| 类别 | 示例 | 要求 |
| --- | --- | --- |
| 秘密 | 密码、token、Cookie、密钥、连接串 | 不进日志/前端产物/离线包；保险库或 secret 引用 |
| 受限证据 | Trace、截图、响应体、可能含业务数据的制品 | Workspace 授权下载；独立访问控制；可配置保留期 |
| 结构化结果 | 步骤/断言结果、Run outcome | 按 Workspace 隔离；导入带来源标识 |
| 运营日志 | 审计、访问、维护任务 | 英文消息；脱敏；可检索但有保留策略 |
| 账户资料 | 邮箱、显示名 | 最小必要；禁用/删除流程明确 |

## 2. 收集最小化

- 只收集功能所需字段；禁止「先全抓再过滤」。
- AI 调用只发送任务所需、允许且脱敏的上下文，禁止发送秘密、原始证据或整个 Workspace 的数据。Provider 密钥仅用于对获批准端点鉴权。发送内容受预算与审核约束。对话 Agent 的会话只向当前有权的所有者开放，私人对话不得进入工作区共享的 AI 历史。见 [AI Provider ADR](../../docs/decisions/0015-模型服务接入边界.md)及[对话测试 Agent 规格](../../docs/specs/conversational-test-agent.md)。
- 前端与桌面不得缓存明文秘密到可复制的本地未保护存储。
- 联网执行中的静态行正文和 HTTP 映射值只通过授权通道进入受控执行进程内存，禁止写入生成源码、下载产物、工作目录、IPC 持久缓存、SQLite、日志及本地报告。可能回显这些数据且无法可靠脱敏的截图、Trace 或其他证据须按任务禁止采集。下载权限不能授权这类采集。见[联网数据集规格](../../docs/specs/veriq-datasets.md#本地数据生命周期)。

## 3. 访问控制

- 证据与原始制品下载必须校验当前 Workspace 成员及相应权限。原始 Attempt 证据须单独验证 `MANAGE_ENVIRONMENT` 和 Attempt 关联。禁止凭 URL 绕过授权。见[原始证据 ADR](../../docs/decisions/0014-报告与证据存储.md)。
- 服务账号令牌范围最小化；不得用个人会话冒充自动化身份。
- 未经授权的跨空间访问和直接跨空间引用须拒绝并审计。仅可按批准规格执行明确授权的跨空间操作。复制已发布数据集时，须校验当前的源 Workspace 下载权限和目标 Workspace 编辑权限，生成独立目标草稿。见[联网数据集规格](../../docs/specs/veriq-datasets.md#数据集资产)。

## 4. 留存与删除

- 服务端原始证据与可过期制品按可配置保留期，通过认证维护接口有界清理。运营日志须有保留策略，最小审计记录按现有运维协议保留。活动任务、共享或固定引用及未满足清理条件的数据不得按年龄盲删。见[服务端运维](../../deploy/OPERATIONS.md)。
- 本机证据与缓存走本机有界维护。活动或隔离占用、停止未知、待上传或引用关系未知时保留现场。见[本机持久化与维护](../../docs/validation/tasks/V11-local-durability.md)。
- 清理失败须可观测；不得把清理失败伪装成业务 PASSED。
- 用户/空间停用或撤销后：阻断新访问；已下载离线副本无法保证远程擦除，须在产品文案与规格中如实说明。
- 备份中的敏感数据与生产同等保护；测试不得使用未脱敏生产转储。

## 5. 展示与导出

- UI 对已保存秘密只显示掩码或元数据。获授权的签发流程只在当次向操作人交付新令牌，交付值不进入持久客户端存储、日志或后续查询。见 [Security Standard](./security-standard.md#4-密钥与敏感数据)。
- 历史离线导出包禁止包含密码、Cookie、设备 token 或其他秘密。认证数据只允许公开适配器元数据与精确凭据版本引用。此规则只约束历史兼容范围，见[联网范围修订](../../docs/specs/veriq-datasets.md)和[离线包 ADR](../../docs/decisions/0016-离线资源包边界.md)。
- 报告展示须避免把完整鉴权头或 Cookie 打进可读字段。

## 6. 检查清单

- [ ] 新字段已分类；秘密未进入禁入通道
- [ ] 证据/制品下载有授权
- [ ] 保留期与清理路径存在或明确复用现有维护任务
- [ ] 导出/日志/AI 路径已最小化与脱敏
