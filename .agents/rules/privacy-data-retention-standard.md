# Privacy and data retention standard

行宽口径：源码及注释每个物理行最多 **120 个显示列**，与 IDE 的 120 列标尺一致。
中文及其它全角/宽字符占 2 列，ASCII 占 1 列；缩进、标点和注释分隔符均计入。

约束用户数据、证据、日志与备份中的敏感信息处理及保留期，降低泄漏与合规风险。

## 1. 数据分类（实现时按类处理）

| 类别 | 示例 | 要求 |
| --- | --- | --- |
| 秘密 | 密码、token、Cookie、密钥、连接串 | 不进日志/前端产物/离线包；保险库或 secret 引用 |
| 受限证据 | Trace、截图、响应体、可能含业务数据的制品 | Workspace 授权下载；独立访问控制；可配置保留期 |
| 结构化结果 | 步骤/断言结果、Run outcome | 按 Workspace 隔离；导入带来源标识 |
| 运营日志 | 审计、访问、维护任务 | 英文消息；脱敏；可检索但有保留策略 |
| 账户资料 | 邮箱、显示名 | 最小必要；禁用/删除流程明确 |

## 2. 收集最小化

- 只收集功能所需字段；禁止「先全抓再过滤」。
- AI 调用不得默认上传完整生产密钥或与任务无关的整库证据；须受预算与审核约束。
- 前端与桌面不得缓存明文秘密到可复制的本地未保护存储。

## 3. 访问控制

- 证据与原始制品下载必须校验 Workspace 成员与角色；禁止「知道 URL 即下载」。
- 服务账号令牌范围最小化；不得用个人会话冒充自动化身份。
- 跨空间访问一律拒绝并审计。

## 4. 留存与删除

- 原始证据、日志、过期制品须有可配置保留期，并通过认证维护接口有界清理。
- 清理失败须可观测；不得把清理失败伪装成业务 PASSED。
- 用户/空间停用或撤销后：阻断新访问；已下载离线副本无法保证远程擦除，须在产品文案与规格中如实说明。
- 备份中的敏感数据与生产同等保护；测试不得使用未脱敏生产转储。

## 5. 展示与导出

- UI 不回显秘密原文；至多显示掩码与元数据。
- 导出包默认不含密码/Cookie/设备 token。
- 报告展示须避免把完整鉴权头或 Cookie 打进可读字段。

## 6. 检查清单

- [ ] 新字段已分类；秘密未进入禁入通道
- [ ] 证据/制品下载有授权
- [ ] 保留期与清理路径存在或明确复用现有维护任务
- [ ] 导出/日志/AI 路径已最小化与脱敏
