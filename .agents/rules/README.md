# Rules

本文件是 `.agents/rules/` 的索引。每条说明规范的用途和适用时机。具体条文见对应文件或章节。

源码与注释的统一要求见《编码与工程规范》的[显示列宽的统一计算](./coding-standard.md#11-显示列宽的统一计算)与[注释正文长度](./coding-standard.md#12-注释正文长度)。

## `coding-standard-rules/` 下的语言指南

这两份是语言细则。`coding-standard.md` 写明跨语言强制约定，并要求语言细节以专项指南为准。

| 文件 | 用途 | 何时阅读或适用 |
| --- | --- | --- |
| [python-coding-standard.md](./coding-standard-rules/python-coding-standard.md) | Python 风格指南，列出 Python 程序应当遵守和应当避免的做法。文首的 VeriQ 改编是规范性的，与 Google 原文不一致时以改编为准。 | 编写或审查 Python 源码的语言用法和风格时。 |
| [typescript-javascript-coding-standard.md](./coding-standard-rules/typescript-javascript-coding-standard.md) | TypeScript 与 JavaScript 风格指南。术语采用 RFC 2119。示例只说明规则，示例中的可选格式不是额外规范。文中的 VeriQ 格式规则是规范性的，与 Google 原文不一致时以该节为准。 | 编写或审查 TypeScript 或 JavaScript 源码的风格时。 |
