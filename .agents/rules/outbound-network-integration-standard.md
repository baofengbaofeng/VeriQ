# Outbound network and integration standard

行宽口径：源码及注释每个物理行最多 **120 个显示列**，与 IDE 的 120 列标尺一致。
中文及其它全角/宽字符占 2 列，ASCII 占 1 列；缩进、标点和注释分隔符均计入。
注释长度只统计有效正文的 Unicode 字符，不含缩进与注释符号。
独立单行及块注释首行有效正文为 40～120 字符；块注释续行不设 40 字符下限。

约束控制面/Runtime/桌面发起的外部调用与集成点，防止 SSRF、凭证泄漏与不可控重试风暴。

## 1. 出站调用清单思维

凡新增强依赖外部系统的能力，须写明：

- 调用方（srv / runtime / desktop）
- 目标类型（AI Provider、对象存储、被测系统、更新源、邮件等）
- 鉴权材料存放位置
- 超时、重试、幂等与失败关闭行为
- 是否可能触及用户内网（SSRF 风险）

## 2. SSRF 与 URL 安全

- 由用户或 Workspace 配置的 URL（环境地址、Webhook、Provider Endpoint、制品 URL 等）必须校验协议与目标；默认禁止指向链路本地、云元数据等危险地址（按部署模式可配置但须安全默认）。
- 禁止把未校验的用户 URL 直接交给服务端请求库「代抓」。
- 重定向跟随策略须受限；不得通过跳转绕过允许列表。
- 文件/制品下载路径由服务端生成与鉴权，不接受任意本地路径或未签名外链充作内部制品。

## 3. AI 与第三方 Provider

- 未配置 Provider 时主路径仍可用；测试默认无真实密钥。
- 出站调用受预算、超时与审计记录约束；失败不得拖垮队列。
- 禁止将完整设备 token、DB 密码或未审核草稿自动外发并发布回资产库。
- Provider SDK 经适配器接入；禁止在业务层散落裸 SDK 调用与硬编码密钥。

## 4. 对象存储与制品

- S3/兼容存储凭据仅存服务端安全配置；最小权限桶策略。
- 上传完成以服务端校验与清单为准；客户端不得宣称「已上传成功」绕过校验。
- 公共读桶不是默认；下载经授权与短时许可机制（按规格）。

## 5. 外部调度与 Webhook

- 平台不设内部 Cron；外部调度调用认证 HTTP 接口。
- 入站触发已在 API 规范约束；若做出站 Webhook，须签名/密钥、超时、有限重试与重放防护。
- 重试须幂等；副作用未知时停止重试并告警。

## 6. Runtime 访问被测系统

- 被测前后端地址来自环境快照与域名约束；执行不得随意扩权访问未声明主机。
- 本地离线仍需被测系统可达；不得为「方便」关闭域名约束。
- 代理/证书配置须显式、可诊断，且不得削弱 TLS 校验作为默认。

## 7. 检查清单

- [ ] 新出站有超时/重试/幂等说明
- [ ] 用户可控 URL 经 SSRF 防护
- [ ] 密钥不在仓与前端；适配器边界清晰
- [ ] 失败不放大为重试风暴
