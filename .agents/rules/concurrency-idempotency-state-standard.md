# Concurrency, idempotency, and state standard

行宽口径：源码及注释每个物理行最多 **120 个显示列**，与 IDE 的 120 列标尺一致。
中文及其它全角/宽字符占 2 列，ASCII 占 1 列；缩进、标点和注释分隔符均计入。
注释长度只统计有效正文的 Unicode 字符，不含缩进与注释符号。
独立单行及块注释首行有效正文为 40～120 字符；块注释续行不设 40 字符下限。

约束队列领取、租约、fencing、取消与结果写入，降低竞态、重复执行与错误释放容量的风险。

## 1. 状态机纪律

- Run / Job / Attempt / 停止证明等状态迁移必须遵循规格中的合法边；禁止跳跃或「顺手改库字段」绕过服务层。
- 业务结果、清理结果、证据完整性、进程停止证明是不同事实，须分别持久化后再归约。
- 结果归约顺序固定：`ERROR > INCOMPLETE > FAILED > CANCELLED > UNSTABLE > SKIPPED > PASSED`。禁止只存最高优先级字符串而丢弃原始事实。

## 2. 租约与 fencing

- 默认心跳 10s、租约 60s；过期不得复活为「仍持有执行权」。
- 所有变更执行中状态的写入须校验 lease / fencing；迟到或旧 fencing 的回报必须拒绝或隔离，不得覆盖新代结果。
- 逻辑取消、超时、PID 不存在，均不等于已证明进程停止。

## 3. 幂等

- 外部触发、结果导入、维护批次、制品上传完成回执等须支持幂等键或等价去重。
- 写入前先按业务键查询；副作用未知时禁止盲目重试导致重复外部写入。
- 离线导入不得覆盖在线 Attempt 权威记录；重复导入须安全且可识别。

## 4. 容量与隔离

- 遵守未结束 Run、全局/空间/离线浏览器并发上限。
- 停止未确认、失联、未知进程：占用隔离容量，禁止当作空闲释放。
- 仅浏览器任务占用浏览器容量；编译/清理使用各自配额，不得混用导致误限流或误放行。

## 5. 重试

- Playwright `retries=0`；整用例重试至多 1 次，由 VeriQ 编排，且使用新 Context / fixture / 工作目录。
- 重试后通过记 `UNSTABLE`；默认门禁不通过。
- 不可重试错误（鉴权、契约、签名、明确业务断言失败等）不得自动整用例重试。

## 6. 并发安全实现要求

- 领取与容量扣减须在数据库事务中原子完成；依赖 MySQL 能力（如 `SKIP LOCKED`）时，doctor/迁移入口须拒绝不支持环境。
- 禁止用「先读后写无版本」更新共享计数或 Attempt 终态。
- 本地 SQLite / 文件锁路径须处理崩溃恢复与代际 CAS，不得假设进程永不死亡。

## 7. 必测负例

- 双 claimer 竞争同一 Job
- 租约过期后的迟到 finish
- fencing 旧值上报
- 取消与完成乱序
- 重复触发 / 重复导入
- 停止证明缺失时容量未释放

- [ ] 状态迁移经服务层且合法
- [ ] lease/fencing/幂等已覆盖写入路径
- [ ] 不确定停止不释放容量
- [ ] 竞态与乱序负例有测试
