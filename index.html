Core capabilities

Versioned test assets

Manage page elements, actions, assertions, and test data as reviewable, versioned assets.

Reproducible execution

Run tests with a fixed asset version, environment snapshot, and browser toolchain.

Step-level evidence

Use step results and browser traces to investigate where a test failed.

From test assets to results

  1. Prepare test assets

    Define actions, assertions, and test data.

  2. Publish a version

    Release the reviewed assets as a fixed version.

  3. Run the test

    Run that version against an environment snapshot.

  4. Review the report

    Inspect step results and trace evidence.

System architecture

The control service manages assets, jobs, and reports. Independent runtimes execute browser tests in the cloud or on a local device.
