## 附近门禁与限制

- 完整 Web 套件在初版实现上执行，27 项通过，包括真实安装登录、角色调整、密码恢复和工作区邀请。8 项进入 Agent 流程时返回 `DOCTOR_FAILED`。夹具指定的 Playwright Chromium 158 可执行文件缺失，官方下载与容器分发返回 403。管理台和静态应用浏览器验证使用现有测试配置允许的系统 Chromium。
- 扩展工作区检查中，契约套件 293 项通过，使用 15 秒 CLI 测试超时。编译器 118 项通过，Runner SDK 146 项通过及 1 项跳过。Runtime 套件 1030 项通过、6 项失败，覆盖缺少锁定浏览器或测试引擎、旧编译器输入、文件系统容量断言和独立桌面暂存夹具。完整运行时与正式发行门禁另行验收。
- 全仓注释审计仍报告不完整覆盖和历史违规。受影响源码采用现有行宽及块注释布局检查和定向评审。
