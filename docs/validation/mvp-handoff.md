## 接手规则

1. 读取 `AGENTS.md`、需求规格、主里程碑和代码交付计划，记录实际分支、提交、锁文件和目标平台。
2. 使用独立工作目录与测试数据库；禁止使用真实业务数据或替换已有证据。
3. 先确认前置条件，再执行每项任务；缺少环境、凭据或人工授权时标为阻塞，不得自动跳过并计入通过。
4. 按批次执行定向检查，再做完整集成与整分支复审。任何修复应形成新提交，并明确哪些旧结果已失效。
5. 保留失败、日志、实际执行命令、退出状态、提交与产物摘要；不要求为每个命令重新封存整个仓库。
