# 验证与验收索引

按需求查找验收范围，再进入对应任务核对前置条件、通过标准和实际证据。提交、工具链和目标环境以各次执行记录为准。

## 验证资料

| 文档 | 用途 |
| --- | --- |
| [首版验证交接](首版验证交接.md) | 查阅接手规则、执行顺序、历史失败和各任务的证据边界。 |
| [需求验收矩阵](需求验收矩阵.md) | 将 F01–F14 对应到实现入口、独立任务和应观察的行为。 |
| [原生源码注释解析预检](原生源码注释解析预检.md) | 查看原生注释解析候选的实测限制、证据及待确认的门禁边界。 |
| [网页管理台验证结果](网页管理台验证结果.md) | 核对网页管理台已执行的回归、静态资源检查和焦点修复。 |
