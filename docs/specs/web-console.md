# Web Console

管理台服务于测试设计、执行、报告和账号管理。用户需要在同一视口里看清业务数据、筛选条件和操作入口，并能通过固定的导航结构在现有页面间切换。

## 布局与字号

- 登录后的页面使用一条横跨窗口的 Banner，下方为导航栏和主内容区。Banner 在 1280px 及以上高度为 77px，内部控件垂直居中。彩色 VeriQ Logo 及其链接区域为 42×42px，其余按钮、链接和选择控件高度不超过 32px，适用于鼠标和触屏。图标按钮采用 32px 方形，头像、图标及间距按紧凑布局调整。左侧放置彩色 VeriQ SVG。右侧依次放置 TailAdmin Default Dropdown 样式的全局工作区菜单、加号添加按钮、齿轮设置链接、主题按钮和用户菜单。工作区切换前用 14px 粗体显示「当前工作区」（英文为 Workspace），竖线居中分隔设置链接与主题按钮。工作区分页操作放在下拉菜单内。较窄时通过省略号按钮展开右侧控件，空间不足时分行排列。
- 顶栏的工作区、用户和语言菜单使用 32px 常规选项行，菜单选项与姓名使用 12px，邮箱和语言标记使用 11px。工作区菜单跟随触发器宽度并保留最小可读宽度，选项名称以单行显示，超宽处显示省略号，完整名称保留在提示及可访问文本中。浮层在窄屏保持在视口内。
- 用户菜单顶部显示真实姓名和邮箱，分隔线下提供账号设置和带当前语言标记的语言子菜单。退出单独置于底部并用红色文字及图标。中文和英文选择即时生效，保留当前页面、工作区和未提交表单。
- 桌面侧栏宽 180–200px，菜单最多两级。选中项清楚标记，直接打开路由时展开所在分组。窄屏可通过具名按钮展开导航，并能在选定页面后收起。
- 页面标题和品牌名称 14px。正文、导航、按钮、表单和区块标题以 13px 为主。表格表头、单元格和行内操作统一 12px，辅助提示 12px。触屏文本输入允许 16px。
- 主区使用侧栏以外的横向空间。页标题与主操作同排，表格和操作区独立分组，筛选和表单区块用浅灰背景，输入控件保持白底。窄屏可折行，宽表格在自身容器内滚动。
- Web 控件在鼠标点击或触屏点按时使用中性色焦点反馈。输入框的聚焦边线为中性灰，按键导航使用清晰的灰色外轮廓，系统强制配色下使用系统焦点色。
- 资源页体现预览的操作方式。标题区提供新建入口，类型筛选使用页内工具栏，当前工作区由 Banner 决定，资源列表保留既有游标。新建时在主区显示浅灰表单，可返回原列表。完整的资源编辑抽屉继续承载编辑、校验和发布。

## 接入边界

使用 TailAdmin React Free `v-2.0` 固定提交 `9aaac11e9e6fa87d0afe0e976b5ac291e29eeeb9` 的头部、分组侧栏、表单和表格结构。保留 TailAdmin 的 MIT 声明。工程使用现有 React 18、Tailwind 3、Vite、Radix 和 i18next。

Banner 尺寸、右侧圆角控件及用户菜单对齐 TailAdmin React Free `v2.5.1` 源码 `486ed748b21e032a4432effeca4ef3684fa223d3`，现有 Web 组件承载实际行为。

登录会话的工作区选择在页面间共享。添加工作区在当前页面打开居中的 TailAdmin 表单弹窗。标题与字段左对齐，底部提供描边取消按钮和主色创建按钮。常规主题下输入框以底色提示焦点，沿用静止边线。创建成功后切到新工作区。报告、执行计划和 Agent 的深链接在取得成员授权后选择其目标。切换身份清除前一个会话的选中项及请求。

齿轮进入现有 `/workspaces` 工作区设置页。工作区入口位于顶栏，侧栏不再显示工作区子菜单。
设置页使用 TailAdmin 带图标的下划线标签，支持键盘导航和链接定位。

- 基本信息是默认标签，显示工作区状态、当前角色、重命名和归档操作。
- 成员标签包含成员列表和邀请管理，接受邀请后的入口直达该标签。
- AI 设置标签包含 Provider 配置、用量预算与连接测试，生成与历史记录由 AI 页面提供。

各标签沿用现有工作区权限和归档限制。样例导入保留在页面标题区域。

账号设置从用户菜单进入现有 `/account`。页面按 TailAdmin Profile 的左侧标题、右侧面包屑、圆角外卡及内部卡片组织。头像使用用户姓名生成首字，资料只显示系统已有字段，密码及会话使用既有操作。账号区标题字号上限为 16px。

Web 默认浅色。主题按钮在浅色和深色之间切换，在当前浏览器持久化，Portal 与 Web 页面随主题更新。访客可切换语言，登录和账户恢复继续使用既有路由。界面保留服务端处理的会话、管理员权限、Workspace 授权及表单行为。Web 外壳及主题由 Web 入口引入，共享的桌面视图继续使用桌面入口。
