# VeriQ 工作区数据集与联网执行

## 已确认的产品范围

MVP 由联网客户端执行测试。客户端连接 VeriQ 平台领取任务与回传结果，并访问被测系统。HTTP 数据源由平台服务端访问。平台连接不可用时停止领取，执行中的任务按租约取消和清理。恢复后由平台决定是否重新调度。被测系统不可达时，结果区分连接错误与断言失败。

本规范覆盖现有 MVP 文档、桌面规格和离线 ADR 中的离线执行范围。F12 的离线任务、签名离线包的产品交付、离线结果导入与相应验收退出 MVP。已生成的历史记录及数据库结构仍可用于兼容核对。新版发布入口只呈现联网执行路径。数据集无离线导出例外或管理员开关。

## 数据集资产

沿用 Workspace 内的 `DATASET` 资源、修订号和发布回执。版本化字段声明包含类型、是否必填和是否可空。每行包含稳定且版本内唯一的 `key` 与 `values` JSON 对象。树形数据使用 `parentKey` 与同级顺序，并校验孤立节点、重复键、循环和深度。同级相同顺序以节点键决定次序。表格和树均可由静态数据或 HTTP 数据源提供。旧版 `DatasetV1` 按原语义读取。

Web 与已登录桌面端共用资源页和服务端接口。提供静态表格和树编辑、CSV/JSON 导入预检、版本差异与引用影响。保存草稿使用现有修订号，数据经校验与发布后不可变。跨工作区复制源已发布版本需要对源有下载权限、对目标有编辑权限，生成独立目标草稿。复制 HTTP 配置后，目标工作区重新配置环境、批准的连接和凭证。源与目标工作区均执行当前授权校验。

## 用例与断言

保留 CASE/SUITE 当前行绑定 `{{data.*}}`，套件从冻结的静态数据行物化执行矩阵。额外的数据集通过命名别名绑定到当前 Workspace 的已发布版本。断言支持按键取字段、成员检查、受限过滤和树路径/子项。命名绑定及查询按类型编译，取字段缺失是数据源错误，成员检查无匹配返回 `false`。保留显式 `null`、空集合和缺失的区别，预期值不可由同一次被断言的观察事实直接充当。HTTP 依赖提供断言预期值，执行矩阵在 Run 准入时已经固定。

## HTTP 数据源

通过服务端管理请求方法与获批目标、URL 路径、重复 Query、Headers、Body、Auth、响应映射和受控分页。提供脱敏预览及固定输入的签名验证。预定义表达式提供参数选取、按明确比较规则排序、处理重复键、编码、拼接、请求时间戳和获批密码学调用。凭证来自工作区版本化引用并绑定出站目标。TLS 验证、目标白名单、响应预算、并发与超时适用于预览和正式查询。上游拒绝、超限或分页未完成均为数据源错误。

Run 锁定数据集配置版本、映射、环境和凭证版本。读取按断言阶段发生，相同版本、环境与类型化入参由同一阶段的一次读取共享，前后断言和重试分别采样。服务端校验 Attempt、设备、当前租约与 fencing 令牌、工作区权限、依赖版本和当前凭证状态。撤权阻断后续读取。

## 本地数据生命周期

静态行正文及 HTTP 映射值通过授权通道进入受控执行进程内存。生成源码、下载产物、验证与执行工作目录、IPC 持久缓存、SQLite、日志和本地报告均排除数据正文。使用摘要和版本验证字节，受控临时内存超过预算时返回明确错误。可能回显无法可靠脱敏的数据的截图、Trace 或其他证据按任务禁止采集。系统交换区和崩溃转储由部署策略控制。

正常结束、失败、取消、租约到期和崩溃恢复均验证清理与进程状态。旧数据集契约继续可读。含正文的旧编译包只能通过重新验证原冻结依赖得到兼容的联网产物后执行。历史任务目录清理通过受控路径、所属元数据和停止证明核对，保留任务状态和清理错误的证据。Linux 首次清理前持久记录一次性退休授权的使用。恢复时保留已尝试退休的目录及后续写入；原授权缺失或历史日志无法证明首次执行时也保留现场。
