# 0009 运行时登记与授权

<a id="adr-0009-runtime-ownership-enrollment-and-current-authorization"></a>

- 状态：T08 已接受，包括协调者批准的与 T16 的依赖协调。

## 1. 决策记录

每个 Runtime 恰好由一个真实 USER 或 SERVICE_ACCOUNT 所有。所有权、Workspace 绑定、所有者显式同意、位置、当前信任与设备上报能力是不同事实。登记只记录 OFFLINE，不产生 Worker、租约、心跳或历史 Run。能力声明不能批准编译器/SDK 发行；MANAGED_CLOUD 也不自动授予 MANAGED 信任。

人工登记使用 12 字符 base32 批准码（60 位随机熵）及独立 256 位设备轮询秘密。二者十分钟过期，仅保存摘要。已认证所有者检查请求的名称/能力、选择当前 Workspace，并同意私有、指定成员或整个 Workspace 共享。只有轮询秘密可一次性消费批准并取得设备凭据。原生端点不接受 Cookie 身份；人工批准保留既有 Origin 与 CSRF 防护。请求创建在过期窗口内按来源限额，客户端每五秒轮询。登记码和凭据不进入 URL。

设备令牌为 256 位秘密，落盘仅存摘要，绑定单一 Runtime 与 Workspace，24 小时过期且可独立吊销。轮换原子生成一个替代令牌并使前任失效；响应使用 no-store。设备认证与派单策略重新检查所有权，以及当前用户/成员或服务账号授权。变更和授权事务在读取可变身份/Workspace 前取得现有安装级守卫，保持账号禁用与成员撤销的锁序。T09 在实际分配、租约/fence、授权和凭据检查中必须保留此锁序；T08 不实现虚假领取端点。无人值守续期、轮换响应丢失恢复及 Worker 生命周期属于 T10。

将可复用服务账号基础从 T16 提前：`veriq_service_accounts` 以 Workspace 为范围，`veriq_service_tokens` 记录用途、过期、消费与吊销。当前 Workspace OWNER/ADMIN 可创建、列出、禁用账号，并签发十分钟单次使用的 `RUNTIME_ENROLLMENT` 令牌；该用途不提供触发、维护或凭据权限。云端登记将该秘密消费为同一 Workspace 下服务账号拥有的 Runtime。服务账号同意由当前 Workspace OWNER/ADMIN 管理；无成员身份的全局管理员没有项目访问权。T16 扩展这套精确身份和用途绑定令牌，不引入第二套身份模型。

只有当前可访问所绑定 Workspace 的系统管理员，才能在已有显式所有者共享同意范围内授予 MANAGED。凭据投递还单独要求当前 Workspace OWNER/ADMIN（MANAGE_ENVIRONMENT）。系统管理员可以只是 Workspace VIEWER/EDITOR，批准硬件信任，但不能授权投递该空间秘密。非全局的 Workspace OWNER/ADMIN 可在独立 MANAGED 批准与所有者同意后，通过 PUT `/api/v1/workspaces/{workspaceId}/runtimes/{runtimeId}/credential-delivery` 和 `{allowCredentialDelivery:boolean}` 授予投递。组合信任更新只有操作者同时具有 MANAGE_ENVIRONMENT 时才可开启投递；系统安全降级始终可清除它。任何同意变更都会重置信任及投递批准；私有同意不授权管理员派单。吊销阻断新设备操作，不重写历史结果。T09/T11 分别保留 gateAtExecution，并按当前信任计算 gateNow；T08 不合成历史结果。

DeviceCredentialsDTO 保留 `runnerId` 并添加批准的初始 `workspaceId`。在 T14 提供真实 Ed25519 包签发者前，`issuerId` 与 `trustedKeys` 作为成对可选字段；T08 二者均省略。没有可信签发者时，包验证必须明确失败。T14 必须通过已认证的绑定控制端来源或获批准的带外部署提供真实根，绝不能让下载包自证信任。

Node 开发环境在 env-paths 下的私有目录/文件保存本地设备配置，使用 proper-lockfile 串行化。这是明确的开发接缝，不声称为 OS 凭据保险库；T20 提供原生打包与系统保险库存储。CLI 秘密经有界 stdin 或私有配置进入，不经过 argv。Doctor 检查真实 Node/OS/架构、引擎包、浏览器可执行文件和启动，以及已配置服务端可达性，使用退出码和脱敏诊断报告失败。控制服务运行时不依赖 Node 或浏览器。
