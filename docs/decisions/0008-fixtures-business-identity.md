# ADR 0008: fixture lifecycle, pinned identities and restricted evidence

Status: accepted for T07. Scope follows the approved full VeriQ specification.

Cases declare `fixtureInput` as an explicit binding object. Omission means `{}`. Inputs resolve from the selected data row and initial variables and validate before authentication or fixture side effects. Fixture output validates before assignment; cleanup tokens remain separate from ordinary variables and source. Prepare is POST, query is GET, cleanup is POST or DELETE with a JSON body. No cleanup token enters a URL. Idempotency binds Workspace, case execution and Attempt number; namespace closes durably during cleanup, including an unknown/partially prepared namespace. A business commit must atomically recheck namespace state. Client cancellation does not prove server rollback.

An Environment's optional `fixtureBaseURL` and `fixtureIdentity` appear together. Its fixture identity is independently version-pinned and must have explicit allowed identities. It never inherits the business role's credential or browser session. Built-in `HTTP_BEARER` and `HTTP_SESSION` adapters use fixed relative login/identity paths and an RFC6901 identity pointer. Configuration is immutable, Workspace-owned and revocable; it is not a ninth asset kind and accepts no uploaded code. Bearer headers are scoped to the exact API origin, including individual browser redirect hops and SDK HTTP calls. Session cookies transfer to the business context only after identity verification. Fixture sessions remain isolated.

`AuthAdapterVersionV1` freezes `{workspaceId,versionId,contentHash,configuration}`; contentHash is SHA256(JCS(configuration)). An AssetSnapshot that actually contains Environment assets retains their exact adapter closure in optional `authAdapters`. Its source-hash projection includes that field only when present, sorted by versionId, preserving older absent-field hashes. Ordinary compiled CASE sources remain reusable across environments. Their separate ExecutionSnapshot retains the selected role/fixture adapter closure. Compiler assembly checks workspace, configuration hashes, exact adapter and secret pins, duplicates and extras; where the selected Environment is retained in source it compares it too. This is integrity checking, not authorization: T09/T10 must freeze from the trusted registry/published Environment, check current revocation, and authenticate the manifest's hash of the full ExecutionSnapshot. T14 must retain the selected profile in the signed offline closure.

Credential values use cryptography AES-GCM, random 96-bit nonces and JCS AAD binding Workspace/reference/version. External settings select an active master key ID and a previous-key map. Rotation creates new immutable versions; no resolution silently substitutes a newer version. Management, listings and revocation require current Workspace OWNER/ADMIN via MANAGE_ENVIRONMENT. Management responses never return plaintext. A typed injectable Attempt verifier is denied by default until T08/T09 implement actual device identity, current membership/grants, assignment, lease and fence. Personal/offline execution defaults to exact local mappings.

Playwright raw Trace is known to contain authentication headers, cookie values, action values, DOM snapshots and business data. Raw screenshots, Trace and downloads default to CREDENTIAL_RESTRICTED; this implementation does not claim to sanitize arbitrary pixels or ZIP resources. Ordinary reports receive redacted structured steps, assertion results, errors and metadata without raw paths/bytes. Authentication/cookie headers are always masked; resolved credential, session and cleanup values are registered for masking. The SDK's explicit privileged local capability is not server authorization. T12 must enforce current Workspace/Attempt access plus MANAGE_ENVIRONMENT for restricted bytes, reject producer downgrades, propagate sensitivity through artifact metadata/events/manifests/export, and preserve privileged local Trace viewing. Production artifact storage/upload/download enforcement is not implemented by T07.
