# 0006 确定性编译产物

<a id="adr-0006--deterministic-compiler-files-and-sdk-handoff"></a>

- 状态：已接受的 T05 实现边界；生产 SDK、fixture 执行及可信 Runtime 完成仍属于 T06/T07/T08–T10。

## 1. 决策记录

编译器仅面向 Node，消费规范契约及 RFC8785 字节辅助函数，不改变它们可在浏览器使用的根入口。Node crypto 验证源码身份及每个文档信封。Ajv 8.18.0 和 ajv-formats 3.0.1 校验 fixture/断言 JSON Schema，不加载远端内容。TypeScript 5.9.3 作为编译器运行依赖，用于确定性 AST 发射。这些精确版本已经批准并锁定；不引入替代 DSL Schema 或密码学实现。

`compileFiles(snapshot, distribution)` 返回严格的 `CompiledAssetBundle` 描述符及包含全部真实文件的路径到 Uint8Array 映射。`compileAssets` 是只返回描述符的兼容包装，同样要求显式发行输入。缺少发行输入时以 `ENGINE_DISTRIBUTION_REQUIRED` 失败，不提供虚假 SDK、归档或完整性。调用方提供已批准引擎发行的精确 package.json、npm v3 package-lock.json、完整依赖库存及本地 vendor 归档。编译器验证引擎/SDK 版本、包与锁一致性、依赖闭包和 SHA-512 归档完整性，不安装或执行归档。可信发行来源、安全解包及批准包内容仍由引擎/Runtime/导入器负责。编译器测试中的夹具明确是隔离代码生成/打包产物，绝不是生产 SDK 回退。

可执行文件向 `@veriq/runner-sdk` 注册类型化编译用例。单一生成文件 `source/context.ts` 为所有用例入口共享冻结源码上下文，避免完整闭包随用例数重复。`source/asset-snapshot.json` 为 Workspace、源码和引擎验证提供清单约束的冷下载上下文。CASE/SUITE 的可执行上下文移除临时 validationTarget。零入口库的侧车文件保留 validationTarget，因为 AssetSnapshotV1 要求它；生成的库 TS 只导出不可变资产数据。不发射 Run、Attempt、机器路径、运行数据行或凭据值。源码身份精确沿用 ADR 0005 的投影。

SUITE 验证目标与现有服务端生产器一致，选择去重且固定的 CASE 版本 ID，并发射可执行用例入口。其余六种非 CASE 资源只产生验证库，不能组装为 TEST。没有验证目标的执行源码可保留恰好一个 SUITE 根，其去重用例必须与入口选择一致；多个匹配套件根按歧义拒绝，其他不可达资产仍为错误。因此可以移除发布元数据，同时保留冻结套件闭包。

流程保留嵌套调用边界：观察器覆盖所有子项，包装断言和提取仍属于包装步骤。模板及流程参数在调用方作用域中只求值一次，覆盖当前作用域 `data`；提取值及 fixture 值放在 `vars`。计划区分前置断言、提取前响应断言，以及依赖新提取值的断言。SDK 必须按阶段执行、保留字面数据、校验提取值存在性与类型，并在所有退出路径释放观察器。生成的传输 ID 是从确定性展开路径推导的固定长度 SHA-256 键，可读路径另存元数据；原始 DSL 留在源码上下文。

流程最多嵌套五层，每个用例/独立流程展开后最多 500 步，含调用边界。断言模板同样最多五层，每个用例/独立库最多访问 5,000 个展开断言节点，含模板调用节点。额外广度限制防止紧凑的重复模板 DAG 引发指数级分配。超限返回语义问题，不在数组展开中抛异常。动作要求具体类型时，未知输入类型失败关闭。可选值缺失与 null 区分；绑定和 JSON Pointer 仅解析自有属性，绝不 eval，也不递归插值已解析数据。

为使覆盖率证据可复现，`@vitest/coverage-v8` 固定为与 Vitest 一致的 4.1.12。新增锁定的十个包声明 MIT 或 BSD-3-Clause，记录在 npm 库存中；相应发行必须附上游许可原文。2026-11-11 审计没有新增公告，仅保留 ADR 0003 已评估的中等级别、仅构建工具 minimatch GHSA-g3hv-75wg-m249。Vite 沿用既有固定 6.4.5 测试/构建依赖。本编译器任务不新增 Python、浏览器 SDK 或生产服务依赖。
