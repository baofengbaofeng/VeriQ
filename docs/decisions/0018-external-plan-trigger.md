# ADR 0018：外部计划触发与独立服务身份

状态：2026-11-13 经协调者预研确认，实施中。

服务账号独立于员工登录。执行令牌 purpose=EXECUTION，24小时有效，明确限定 Workspace、计划 ID 和 trigger/read/cancel 操作；created_by 仅保留归因。服务校验贯穿准入、领取、心跳、凭证和完成，实时检查账号/令牌/计划/设备绑定与所有者同意。服务自有设备或明确共享到 Workspace 的设备可用，管理员不因创建账号获得私人设备派单权。

计划修改采用 revision；触发冻结已发布资产、环境、角色、浏览器、变量和 Runtime 选择。幂等键绑定调用主体、计划 ID 与调用输入，重放不读取新计划配置重新排程。QUEUE 按计划单调序号串行，早期 Run 完成但物理资源未释放仍阻止后续领取；SKIP 产生无 Job 的终态记录，REJECT 返回冲突。原有10个未完成运行、全局4/空间2容量和1000矩阵上限保留，展开前先核算矩阵。

Bearer 分支显式校验，失败不回退 Cookie；普通 Web 保留 Origin/CSRF。CI 使用安全结构化报告事实及 Python 标准库 ElementTree 输出仅标识、状态的 JUnit，不向执行令牌开放原始 JUnit/Trace/HTML。无需新增第三方依赖；既有执行引擎与统一队列不变。
