# 0016 Offline Bundle Boundaries

状态：T14 实现决策，日期 2026-11-11。

控制器使用 Python 标准库 zipfile 导出有界 ZIP 数据，Node 使用固定 yauzl 3.4.0（MIT）惰性读取并验证大小。Ed25519 使用 cryptography 与 node:crypto；这里不打包平台相关 node_modules 或浏览器。

manifest.json 原始字节及独立 manifest.sig 认证其他所有列明成员。snapshot.json 绑定选定已发布根、环境与精确闭包；原验证快照、描述符、回执及编译文件保留来源。引擎库存和锁元数据标识独立安装的获批准发行。导出不解析加密凭据；唯一导出的认证数据是公开适配器元数据和精确 secretRef/version 固定引用。

操作员显式初始化用途隔离的签发者文件（0700 目录、0600 文件、原子替换）。重启复用该身份，丢失会阻止新导出；备份必须保留签发者身份与密钥。轮换保留旧公钥，吊销单调且旧密钥仍可识别。身份丢失要求显式可信重新登记或带外再分发，包不能安装自己的信任根。Runtime 将公开签发者状态与可随登出删除的凭据分开缓存。只有已认证 HTTPS 精确来源的设备传输或已核对带外指纹能建立信任。离线验证的吊销状态始终为 UNKNOWN，已知吊销密钥则失败。过期/未验证包要求显式 DEBUG，不能带来正式结果信任；签名有效不证明本地结果诚实。

发布解包文件前先验签。拒绝不安全或歧义路径、大小写不敏感碰撞、链接、加密、多余/缺失条目及超量。限制为 4096 成员、64 MiB 归档、128 MiB 总输出、单文件 16 MiB。资源闭包保留既有 1000 项资产/100 深度/16 MiB 限制。私有暂存目录只在全部摘要验证成功后重命名，再只读暴露。

本地凭据在受限原子配置文件中按精确 issuer/workspace/ref/version 映射。这是规格中的受限配置接缝，不是 OS 保险库；T20 负责原生保险库集成。缺少映射明确失败，不回退在线解析。动态 JSON 成员名含受保护本地秘密值（含 URL/base64 形式）时，扣留整个对象。协议信封单独投影，确保协议自有 ID、状态及序号合法。

`BundleSelectionV1` 是规范请求契约，OpenAPI 仅引用别名。必须恰好选择 CASE 列表、SUITE 或不可变 `draftValidationJobId` 中的一种。草稿导出要求 EDIT 和 UNVALIDATED_DEBUG，每次读取/下载也要求 EDIT。排队 VALIDATE 快照无需 Agent 即可使用：保留原源码/validationTarget 及已发布依赖来源，不含生成 TS，engine/requirements.json 明确要求 T15 在本地匹配编译。已发布导出保留真实编译字节及批准库存/锁元数据。

每个服务进程最多并发两个组装请求。在现有授权事务中收集获授权不可变输入，ZIP/签名在线程中、数据库锁外执行，持久化前再核对当前会话/成员、精确凭据固定版本、签发者状态及批准引擎。包的归档/清单/快照引用固定既有 Artifact 记录；包 14 天、元数据 90 天生命周期属于 T21，不在 T14 私设垃圾回收。

规范资源 DTO 移至共享 Schema，OpenAPI 仍使用别名，不引入第二套资源校验器。原生验证快照提供既有本地只读资源适配接缝，只包含白名单 TS 源码。公开根及单调缓存吊销状态在登出后保留，本地秘密映射被清理。显式删除配置档案（包括信任）仍是独立宿主动作。受限配置准确说明文件权限保证；Windows 原生保险库及安装器验证仍属 T20。新归档图的精确版本、许可摘要和带时间 OSV 结果见 `docs/dependencies/t14-archive-audit.json`。

复审修正：带外指纹固定仅认证已核对的一把密钥，未签名标签/修订与已认证 HTTPS 密钥集修订隔离。版本 2 缓存迁移丢弃全部旧签发者信任，保留指纹吊销拒绝。共享编译器 analyze/verifyFiles/distribution 在只读安装前核对入口、公开认证配置、原源码及编译器/SDK/依赖库存，签名单独不能保证语义一致。同步 201 创建使用增量 0012 的持久 Workspace/key/actor/request 预留（IN_PROGRESS/COMPLETE/FAILED），不自动接管，重放要求当前授权。配置锁依 issuer→inventory→DB 顺序取得并持有到最终提交；读取和压缩仍在 DB 锁外。T18 所需的精确可写守卫路径及操作员晋升协议记录于 offline-bundles.md。UI CASE 选择篮跨资源保留，全部版本选择器按真实分页游标读取。
