## 背景与证据

`feac6e2` 全仓审计仍有三条正文诊断，均为原样保留的 mypy 行尾类型检查指令。
用户已批准有成熟语法上下文与实际工具消费证据的固定词元按 C=0、K 保留计量。
这项维护不调整产品范围、架构、公共接口、依赖族、版本、许可或平台保证。
具体识别边界由协调者根据预检证据选择，不表述为用户逐项指定内部实现。

CPython 3.12.14 的 TypeIgnore 与 COMMENT 坐标确认两个 no-any-return 和一个 arg-type 宿主。
现有 mypy 1.19.1 的合成静态正反例证实精确标记、移除、未使用与错拼的不同诊断。
证据只证明这些语法及消费行为，未声称本次已经重验全仓 mypy。

## 方案比较与选择

| 方案                                          | 取舍与决定                                                           |
| --------------------------------------------- | -------------------------------------------------------------------- |
| 保留普通 AST，附加类型注释 AST 和真实词元资格 | 复用标准库，兼容原文档串口径，能把未知或不合格宿主留在普通验收；采用 |
| 全部改用 type_comments=True 解析              | 会拒绝默认 AST 原本接受的类型注释形式，缩窄旧输入；不采用            |
| 仅按文本前缀或直接跳过整行                    | 无法区分字符串、附加说明、未知码与无代码宿主，也会丢 K；不采用       |

## 决策

完整范围和失败语义见规格。只接纳已实测的两个完整单码词元，K 使用原有代码集合自然去重。
普通 AST 仍为文档串及语法权威，辅助 SyntaxError 降级为不给工具资格，不能扩大其他异常的吞没范围。
普通说明与字面量不获豁免，未知 pragma 不分类，原三个标记字节不变。
相邻短中文说明单独整改，不用工具角色遮蔽它。

同时关闭 ADR 0028 已登记的 Windows Vite 路径断言建议：保留完整解析后绝对路径作为必要子串，
仅将期待路径转成 POSIX 拼写；保留原警告内容、转换次数、隔离及清理断言。
这仍需实际 Windows 工具测试，Linux 通过不能改写成 Windows 已验收。
