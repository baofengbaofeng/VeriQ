# 0002 Project Name Casing

- 状态：用户于 2026-11-10 接受。
- 所有人类可读的项目名称统一使用 **VeriQ**，包括源码注释与文档串、README、文档、规格与计划、API 标题、GUI 标签、安装器显示名称及生成文档。
- 小写机器标识保持不变：数据库前缀 `veriq_`，进程/CLI 名 `veriq`、`veriq_agent`、`veriq_runner`、`veriq_cli`，Python 模块 `veriq_server`，npm 作用域 `@veriq`，以及路径、配置键和 Schema 标识。
- 这是品牌名称修正，不涉及数据库、包名或 URL 迁移。
