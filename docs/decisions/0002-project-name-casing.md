# ADR 0002: Project display name is VeriQ

- Status: accepted by the user on 2026-11-10.
- All human-readable project naming uses **VeriQ**: source comments/docstrings, README, documentation, specs/plans, API titles, GUI labels, installer display names and generated documentation.
- Lower-case machine identifiers remain unchanged: database prefix `veriq_`, process/CLI names `veriq`, `veriq_agent`, `veriq_runner`, `veriq_cli`, Python modules `veriq_server`, npm scope `@veriq`, paths, configuration keys and schema identifiers.
- This is a branding correction, not a database/package/URL migration.
