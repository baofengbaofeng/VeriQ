# 系统接入规范

供被测业务系统团队和 CI 运维人员查阅。按接入任务选择对应规范。

| 文档 | 适用场景 |
| --- | --- |
| [后端接入契约](./后端接入契约.md) | 对齐 HTTP 接口、业务身份、fixture 生命周期、事务边界与验收。 |
| [前端接入契约](./前端接入契约.md) | 设置稳定的 DOM 锚点和组件行为，并关联请求与业务断言。 |
| [外部调度接入](./外部调度接入.md) | 使用受限服务身份触发执行计划、检查 CI 门禁和运行维护任务。 |

公共接口与 Schema 见[公共契约](../公共契约.md)。操作步骤见[使用与接入指南](../guides/使用与接入指南.md)。验收记录与接续事项见[验证与验收索引](../validation/验证与验收索引.md)。
