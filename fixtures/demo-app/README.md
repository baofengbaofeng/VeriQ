# 示例业务服务

`app.py` 是 VeriQ 的受控示例业务与 fixture HTTP 服务，使用 Tornado 和标准库 SQLite。

用控制服务的 Python 环境运行它。`apps/srv` 的 uv 环境已经包含 Tornado。不要在仓库根目录另建一套 Python 依赖。

# Demo business service

`app.py` is VeriQ's controlled demo business and fixture HTTP service. It uses Tornado and the standard-library SQLite module.

Run it with the control-service Python environment. The uv environment in `apps/srv` already provides Tornado. Do not install a second Python dependency set at the repository root.
